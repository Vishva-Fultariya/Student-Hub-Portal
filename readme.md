# StudentHub

## Description

StudentHub is a web-based student portal developed as a semester project for the Web Development Framework subject.

## Features

- Student Login
- Dashboard
- Attendance
- Assignments
- Courses
- Study Materials
- Timetable
- Results
- Notices
- Student Profile

## Technologies

- HTML
- CSS
- Git
- GitHub
