# StudentHub Portal

StudentHub is a static student portal created using semantic HTML5 and responsive CSS.

## Pages
1. Home
2. About Us
3. Contact
4. Login
5. Sign Up
6. Dashboard
7. Profile
8. Study Material
9. Timetable
10. Attendance
11. Result
12. Notice Board
13. Logout

## Practical Coverage
- Practical 1: Project planning, sitemap, wireframe and GitHub setup
- Practical 2: Semantic HTML5 structure and accessibility-ready forms, navigation, images and tables
- Practical 3: Responsive UI using CSS Grid, Flexbox, media queries, Bootstrap and Tailwind

## Technologies
- HTML5
- CSS3
- CSS Grid
- Flexbox
- Media Queries
- VS Code
- Bootstrap
- Tailwind CSS
- Browser responsive inspection

## Responsive Design
The interface adapts for desktop, tablet and mobile screens. Public pages use a responsive navigation layout, while private student pages use a responsive sidebar and content grid.
